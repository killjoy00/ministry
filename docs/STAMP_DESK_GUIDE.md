# Stamp desk — how to file a coincidence

1. Choose an incident in the left tray. Its displayed chance is the natural chance **if attempted**; not every eligible incident occurs naturally every day.
2. Choose Nudge, Misfile, Delay (Reschedule), or Domino. The preview states the possible effect and cost. Selecting a stamp does not file it.
3. File the stamp with X / F. The visible **Filed for Today** text confirms it. Undo or replace it before advancing. Double Booking allows a second stamp on a different incident.
4. Advance Day with Y / Space to resolve any filed stamps and naturally occurring events. Costs are charged on day advancement. Advancing without filing is valid.

Nudge improves the chance, Misfile substitutes an alternate result when supported, Delay retries tomorrow if eligible, and Domino guarantees one newly eligible follow-up only when the stamped parent occurs. WHY? still opens the full causal evidence view.

Controller focus remains on the chosen stamp and moves to Advance Day after filing. This update changes UI only, not rules or saves.
